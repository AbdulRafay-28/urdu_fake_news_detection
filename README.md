
# Urdu Fake News Detection

## Overview
This project is a Machine Learning application that detects whether an Urdu news article is Fake or Real.

## Features
- Fake News Detection
- Urdu Text Preprocessing
- Machine Learning Prediction
- Simple User Interface

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Joblib

## Installation

1. Clone the repository:
```bash
git clone https://github.com/abdulrafay 28/urdu-fake-news-detection.git
```

2. Install the required packages:
```bash
pip install -r requirements.txt
```

3. Run the project:
```bash
python app.py
```
